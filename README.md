# 26Y-Mandatory-Legal-Training

2026년 삼표시멘트 법정의무교육 진행 현황 모니터링 및 임직원 수료 여부 조회 시스템입니다.  
외부 CDN이나 서버 없이 동작하는 **오프라인 단일 HTML** 구조로 제작되었으며, 배포용 공개 페이지(`index.html`)와 내부 관리자용 페이지(`training-monitor.html`)를 빌드 단계에서 완전히 분리합니다.

## 주요 기능

### 1. 관리자 전용 대시보드 (`training-monitor.html`)
- **사이드바 구성 (3개 메뉴)**: `관리자 대시보드` / `일반 조회` / `교육 미대상자` (일반 조회 전환 시에도 상단 전환 스위치 및 사이드바 메뉴 유지)
- **교육진행율 엑셀 업로드**: 우측 상단 **교육진행율 업로드** 버튼으로 새 LMS 수료현황(`.xlsx`/`.html`) 파일을 브라우저에서 즉시 파싱·인사원장(`empMaster`) 매칭 후 화면 갱신
- **일간 교육 진행율 추이 모션 그래프**: 수료일자(`completed`) 기준 일간 신규 수료 인원(막대)과 누적 수료율(라인)을 부서 필터·업로드와 연동해 자동 모션으로 시각화
- **부서별 수료 현황**: 3단계 조직도 트리 / 상위부서별 / 세부부서별 전환, 정렬(미수료 인원순 · 수료율 높은순 · 낮은순), 부서 클릭 시 소속 부서원 확장 표시
- **교육 미대상자 관리**: 인사원장 기준 해상(선박·예비원)·임원·고문 제외 후 휴직·겸직·일반 재직 미등록자 분류 조회
- **우측 상세 패널**: 사번·이름 빠른 검색 및 개인별 과정·진도율·학습일 상세 확인

### 2. 배포용 일반 조회 페이지 (`index.html`)
- **개인정보 보호 및 권한 분리**: 빌드 시 관리자 메뉴·전환 스위치·엑셀 업로드·미대상자(`nonTargets`)·인사원장(`empMaster`)·직위(`position`)·직책(`jobRole`) 데이터를 코드와 JSON에서 완전 제거
- **마스킹 처리**: 조회 결과 성명 가운데 글자 별표(`*`) 마스킹 및 사번 표시
- **상위부서/부서별 진행율**: 조직도 트리·정렬·부서원 확장 및 수강 안내 영상(`mp4` 인라인 임베드) 제공

## 빌드 방법

```bash
python3 training-monitor/build.py study_personal_status20261121000407272.xlsx
```

- 루트 또는 `training-monitor/` 내 `employees_*.xlsx`, `*.mp4` 파일을 자동으로 탐색하여 매칭 및 인라인 임베드합니다.
- 실행 결과로 `training-monitor.html`(관리자용)과 `index.html`(배포용)이 함께 생성됩니다.

## 작성 과정 및 주요 변경 이력

1. **초기 구축 및 보안 분리**
   - LMS 수료현황 엑셀 파서 및 오프라인 대시보드 구축, CSP(`default-src 'none'`) 적용
   - 공개 배포용 `index.html`에서 관리자 대시보드·미대상자·직위/직책 데이터 스트립 처리
2. **인사원장 매칭 및 UI/UX 고도화**
   - 삼표시멘트 CI 블루 테마 적용 및 인사원장(`employees_20261101.xlsx`) 100% 조직 매칭(상위부서·소속부서·사번 보정)
   - 법정의무교육 안내 동영상(`mp4`) 인라인 임베드 및 우측 사이드바 빠른 검색 추가
3. **조직도 트리 및 조회 기능 개선**
   - 일반 조회 메뉴에 상위부서별/부서별 진행율 패널 추가 및 수료율 정렬(높은순/낮은순/미수료 인원순) 구현
   - 3단계 조직도 트리 뷰, 부서 클릭 시 부서원 목록 확장, 전체 보기 토글 및 모바일 반응형 폭 최적화
   - 일반 조회 시 성명 가운데 `*` 마스킹 및 사번 표기 적용, `전체 대상` 타일 클릭 시 전체 필터 초기화 및 생산담당 등 트리 접기/펼치기 버그 수정
4. **관리자 운영 편의 기능 강화**
   - 관리자 페이지 우측 상단 **교육진행율 업로드** 버튼 및 브라우저 내장 `.xlsx` 오프라인 파서 추가
   - 좌측 사이드바를 `관리자 대시보드` · `일반 조회` · `교육 미대상자` 3개 메뉴로 단순화하고, 관리자 페이지 내 일반 조회 화면에서도 전환 버튼 유지
   - 관리자 페이지 전용 **일간 교육 진행율 추이 모션 그래프** 추가 (자동 드로잉 모션 및 마우스 오버 상세 툴팁 지원)
